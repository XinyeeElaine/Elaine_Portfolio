## Projects

**Q: What projects has Elaine built?**
A: Elaine has shipped 10+ projects. Highlights include LoafLand Bakery (Android bakery app), Meow-ney Maker (real-time salary tracker), FYP Predictive API (EV fault-detection ML API), H&Maybe (fashion e-commerce), and FoodTrust (fake-review detector browser extension).

**Q: What is LoafLand Bakery?**
A: LoafLand Bakery is a full-featured Android bakery app by Elaine — online ordering for customers and a management dashboard for admins. Built with Kotlin and Jetpack Compose using MVVM, Room (SQLite) with 8 tables, multi-language support (English, Malay, Chinese), and Material 3. GitHub: github.com/XinyeeElaine/LoafLand-Bakery

**Q: What is Meow-ney Maker?**
A: Meow-ney Maker is a playful real-time salary tracker by Elaine that calculates earnings second-by-second from your monthly salary and hours, with a bouncing cat companion and a DJ Cat for clock-out. Built in pure HTML, CSS, and vanilla JavaScript with local-storage history. Live: meow-ney.sillycookie.me — GitHub: github.com/XinyeeElaine/Meow-ney-Maker

**Q: What is the FYP Predictive API?**
A: The FYP Predictive API is Elaine's EV charger predictive-maintenance project — a Flask REST API that detects charger faults before they happen using a scikit-learn pipeline. Its POST /predict endpoint returns failure probability, risk level, failure category, and a root-cause explanation. Served via Waitress and deployed on Render. GitHub: github.com/XinyeeElaine/FYP_Predictive_api

**Q: What is H&Maybe?**
A: H&Maybe is a full-stack fashion e-commerce web app by Elaine, built from scratch in plain PHP — category browsing, cart, Stripe checkout, order tracking, and an admin panel. Uses PDO with MySQL/MariaDB (12 tables), PHPMailer, and jQuery. GitHub: github.com/XinyeeElaine/HAndMaybe

**Q: What is FoodTrust?**
A: FoodTrust is an AI-powered browser extension by Elaine that detects fake Google Maps restaurant reviews in real time using Amazon Bedrock, showing an overall trust score. Built at the Great AI Hackathon 2025 (Team Penguining) — her first hackathon — on a serverless AWS backend (Lambda, API Gateway, S3) with a vanilla JS extension. GitHub: github.com/XinyeeElaine/fake-food-review-detector

**Q: Has Elaine done a hackathon?**
A: Yes. Elaine's first hackathon was the Great AI Hackathon 2025 with Team Penguining, where she built FoodTrust, a fake-review-detecting browser extension powered by Amazon Bedrock.
